# v0.8 — Removing the asterisks

*Concept note, 2026-07-29. Companion to `triage-design.md` (selection ×
disposition) and `transport-design.md` (identity × driver). Grounded in
`landscape-2026-07.md` (~40 servers surveyed).*

## The finding that shapes everything

The survey ranked ten steal-able ideas. The temptation is to build the top
five and grow the tool count. That is exactly how the field got ugly —
codefuturist has 47 tools, sweetrb 50+, che 53: verb soup, breadth as a
substitute for depth. We scored 44/45 against that field with sixteen tools.

The clean reading of the survey is different. Every unique leg we have is the
same *one* idea wearing different clothes:

> **Frozen intent, deterministic execution, verified against the store.**

The spool freezes a message and verifies delivery. A triage plan freezes a
selection and verifies application. The identity file freezes routing and the
allowlist per address. That idea is the product. Nobody else in ~40 servers
has it even once.

So v0.8 adds **no new tool categories and no new concepts**. It takes the
promises the sixteen tools already make and deletes the fine print on each.
Today, honestly stated:

- *"Search your mail"* — **except bodies beyond the first line** (the
  Envelope Index `summaries` table holds snippets; body search silently
  misses — imdinu's benchmark made this the category's known weakness).
- *"Sends at 9:00"* — **if the Mac is awake near 9:00** (launchd fires on
  wake; a closed lid means late).
- *"Safe by design"* — **if the model passes the right parameters** (delete
  is an action string on the same tool as mark_read; safety by convention,
  not structure).

v0.8 is those three asterisks, removed. Nothing else.

## The three movements

### 1. Complete reads — the FTS5 body index

A local SQLite FTS5 index over `.emlx` bodies (incremental, built from the
same store we already read; `~/.email-mcp/fts/`, rebuildable, never touching
Apple's files). Search stops meaning "search the snippets" and starts meaning
"search the mail" — at the same millisecond latency, over all 305k messages.

This *deepens* the oldest design decision instead of adding one: "the store
is the truth" finally covers all the bytes. It also collapses two survey
polish items for free — view-level enums (MINIMAL/METADATA/FULL) and batch
content fetch are trivial once bodies are locally indexed, and they serve the
same goal: reads sized exactly to the question.

### 2. Durable schedules — the Graph executor

For Exchange identities, `schedule_email` hands the *same frozen .eml* to the
server: a draft carrying `PidTagDeferredSendTime`
(`singleValueExtendedProperties` 0x3FEF), transmitted by Exchange at the
deferred time — lid closed, Mac off, irrelevant. The launchd spool stays as
the universal executor for every other identity and as the fallback when
Graph is unreachable; `list_scheduled` reports which executor holds each
message.

No MCP in the surveyed ecosystem exposes this — including Microsoft's own.
And architecturally it costs nothing new: it is a *driver capability* inside
the existing identity × driver frame. The frozen-intent semantics are
unchanged; only the executor gets a stronger guarantee.

Gate: a feasibility probe against CERN's tenant (Graph delegated access to
the mailbox) before any code. If CERN's tenant refuses, the movement shrinks
to a documented "not possible here" and the launchd spool remains the answer.

### 3. Structural safety — the trust envelope made of shape, not convention

Three small changes, one principle — *dangerous things get their own names
and their own doors*:

- **Segregate the destructive verb**: `delete` leaves the shared `actions`
  vocabulary and becomes `triage_plan_delete` (the Google/Anthropic
  sensitive-op pattern). A fumbled parameter can no longer reach the Trash.
- **`EMAIL_MCP_READ_ONLY=1`**: one env var that hard-disables every mutating
  tool at registration time — the widest possible trust envelope for new
  users, review sessions, and demos.
- **`doctor` diagnostics**: FDA / Automation / Accessibility / transport /
  identity checks as one tool with remediation hints — the category's #1
  support burden answered by the software instead of the README. (Absorbs
  `--transport-check` into a fuller picture.)
- Plus the injection fence the survey flagged as applying to us: reject
  model-supplied header-like content in bodies at compose time (the
  tecnologicachile class), and fence quoted message content in reads.

## What is deliberately NOT in v0.8

- **No watchers, no standing rules, no autonomous triggers.** The triage
  philosophy stands: *the agent is the rule engine*. A watcher that acts is a
  frozen decision; we don't ship those. (A watcher that merely *wakes* the
  agent is coherent — parked as a horizon note, not scope.)
- **No breadth verbs** — signatures, VIPs, vacation responders, rules CRUD:
  the field's verb soup, still rejected.
- **No Gmail/Graph *read* paths.** First parties commoditized hosted reads;
  our read story is local-first or nothing.
- **No rename.** codefuturist owns the "email-mcp" search result; we own the
  `apple-mail` MCP registration name users actually see. The README already
  positions on the five legs; a benchmark page (imdinu's playbook) falls out
  of movement 1 naturally and does the arguing for us — we'd win every write
  column and, post-FTS, tie or win the read columns.

## Why this is the beautiful version

Each movement deepens an existing concept instead of adding one: FTS
completes *"the store is the truth"*; the Graph executor strengthens *frozen
intent* inside *identity × driver*; the safety work makes *the invariant*
structural. Tool count stays sixteen (delete's tool splits out; doctor
absorbs a CLI flag — net +1/-1). A stranger who reads the three design docs
after v0.8 finds no new ideas to learn — only fewer exceptions to the ones
already there.

The one-line version: **v0.7 made every claim routable; v0.8 makes every
claim total.**

## Sequencing

1. **FTS5 body index** — pure local, no external dependencies, biggest daily
   payoff, erases our only benchmarked weakness. First.
2. **Structural safety** — small, independent, ships alongside anything.
3. **Graph executor** — gated on the CERN tenant probe; if green, it is the
   ecosystem's first native deferred send; if red, documented and closed.
4. (Already queued for 0.8 from v0.7: config defaults flip generic — the
   repo becomes person-clean.)
